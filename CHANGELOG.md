# Changelog

- Add native MP4, QuickTime ProRes 4444 and WebM exports alongside PNG → Video.
- Allow resolution scales above 200% through numeric entry for PNG → Video.
- Keep render queue items tied to their composition.
- Add repository setup instructions and clarify color handling in source comments.

Current release targets Cavalry 2.8.0 on macOS. Windows support needs a separate port.
